**状态：§7 五项已确认锁定（2026-10-10，v1.1），可开工。** 锁定结论：

1. 一单**只装一种商品**（多商品拆多单）
2. 带货**按订单记**（不建航班实体）
3. **"已发货给买家"进系统** → 新增「已发货」状态 + `jp_deliveries` 表
4. 少货/错货**单独追踪** → 新增 `order_exceptions` 表 + 异常追踪模块
5. 旧系统历史数据**不迁移**，新系统只管新单
